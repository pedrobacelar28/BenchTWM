# Curated Offline Datasets

This page defines the public dataset variants in `configs/catalog.json`. A
dataset is a fixed collection of simulator trajectories generated by
BenchTWM; it is not a raw clinical dataset and it is not the same thing as an
environment family.

## Dataset IDs

Public IDs follow this form:

```text
<environment>/<behavior-policy>/<tier>
```

For example:

```text
epicare/smart/final
icu-sepsis/expert/dev
```

The public datasets use `state_vector` observations and categorical actions.
The generated files contain `train.npz`, `val.npz`, `metadata.json`, and an
`episodes_summary.csv`. All public datasets also contain `ope_test.npz`
because their catalog entries enable held-out OPE.

## Tiers

`dev` and `final` are dataset-size tiers, not different environments or
different dynamics. They use the same curated environment configuration and
behavior-policy definition; `dev` is intended for fast smoke runs and `final`
is the main benchmark scale.

| Environment | Tier | Train episodes | Validation episodes | OPE episodes |
|---|---:|---:|---:|---:|
| EpiCare | `dev` | 1,000 | 200 | 500 |
| EpiCare | `final` | 100,000 | 10,000 | 20,000 |
| ICU-Sepsis | `dev` | 5,000 | 500 | 500 |
| ICU-Sepsis | `final` | 100,000 | 10,000 | 20,000 |
| DTR AhnChemo | `dev` | 1,000 | 200 | 500 |
| DTR AhnChemo | `final` | 100,000 | 10,000 | 20,000 |
| DTR GhaffariCancer | `dev` | 1,000 | 200 | 500 |
| DTR GhaffariCancer | `final` | 100,000 | 10,000 | 20,000 |

ICU-Sepsis is evaluated directly in its simulator, and its public datasets now
also include held-out OPE. Direct simulator evaluation remains the primary
metric because it measures the deployed policy without importance-sampling
variance; OPE is an additional comparable diagnostic. Expert and optimal
datasets can have narrow support, so their OPE reliability must be reported.

## EpiCare Variants

EpiCare exposes an 8-dimensional symptom observation, 16 categorical
treatments, and a hidden disease state. The disease identifier is retained for
diagnostics but is never an agent input.

Each variant exists as both `dev` and `final`:

| Policy ID | Meaning | Role in the benchmark |
|---|---|---|
| `random` | Samples uniformly among all 16 treatments. | Coverage-oriented lower/reference collection policy. |
| `smart` | Uses EpiCare's ClinicalTrial policy, a nonuniform stochastic treatment distribution. | Default behavior distribution and primary EpiCare dataset. |
| `soc` | Uses the Standard-of-Care policy, selecting treatments from observed symptoms and updating its estimates from rewards. | Adaptive, narrower-distribution behavior stress test. |
| `oracle` | Selects using the hidden disease state and expected instantaneous reward. | Privileged reference/upper-bound collection; not a deployable partially observed policy. |

The corresponding public IDs are:

```text
epicare/random/dev       epicare/random/final
epicare/smart/dev        epicare/smart/final
epicare/soc/dev          epicare/soc/final
epicare/oracle/dev       epicare/oracle/final
```

`oracle` is useful for measuring how much a method loses under partial
observability, but results from its dataset should be labeled separately from
datasets collected by policies that only observe symptoms. Its deterministic
or narrow action support can also make multi-step OPE unstable.

## ICU-Sepsis Variants

ICU-Sepsis is a finite MDP with a 47-dimensional structured state vector, 25
treatment actions arranged as a 5-by-5 fluids/vasopressor grid, and
state-dependent admissible-action masks.

Each variant exists as both `dev` and `final`:

| Policy ID | Meaning | Role in the benchmark |
|---|---|---|
| `random` | Samples uniformly from the currently admissible actions. | Broad coverage and lower/reference collection policy. |
| `expert` | Samples from the packaged upstream expert distribution after applying the action mask. | Main behavior-policy dataset. |
| `epsilon-expert` | Uses `(1 - epsilon) * expert + epsilon * uniform`, with `epsilon = 0.2`. | Expert data with controlled exploration. |
| `optimal` | Uses the deterministic policy obtained by value iteration over the packaged MDP. | Reference dataset for comparison with the known optimum. |

The corresponding public IDs are:

```text
icu-sepsis/random/dev             icu-sepsis/random/final
icu-sepsis/expert/dev             icu-sepsis/expert/final
icu-sepsis/epsilon-expert/dev     icu-sepsis/epsilon-expert/final
icu-sepsis/optimal/dev            icu-sepsis/optimal/final
```

Every ICU behavior policy respects the admissible-action mask. In particular,
`random` does not mean uniform over invalid actions, and `optimal` is a
simulator reference rather than a claim about clinical optimality.

## DTR Variants

The DTR additions use the selective AhnChemo and GhaffariCancer runtimes from
DTRGym, pinned in `third_party/dtr/`. Only `setting1` is public initially:
there is no PK/PD variation, observation noise, or missingness. Settings 2--5
are reserved for future robustness variants and do not change these IDs.

Both environments expose only structured `float32` vectors to agents. Their
`state_ids` are deterministic fingerprints for audit/trajectory bookkeeping;
they are not tabular states, one-hot inputs, or world-model inputs.

| Environment | Public vector | Public action grid | Success |
|---|---|---|---|
| `dtr-ahn-chemo` | 3 features: tumor, immune, drug concentration | 5 dose levels mapped to `[0, 1]` | Survive until horizon truncation |
| `dtr-ghaffari-cancer` | 7 visible features in the simulator's natural-log representation | 5 radiotherapy × 5 chemotherapy levels | Reach the simulator's positive tumor-control termination |

The public IDs are:

```text
dtr-ahn-chemo/setting1/random/dev
dtr-ahn-chemo/setting1/random/final
dtr-ghaffari-cancer/setting1/random/dev
dtr-ghaffari-cancer/setting1/random/final
```

`random` samples uniformly over the complete public action support. Its exact
log propensities are `log(1/5)` for AhnChemo and `log(1/25)` for
GhaffariCancer, so held-out OPE is enabled. Hidden normal-cell, metastasis,
PK/PD, and ODE auxiliary variables are excluded from agent-facing `info` and
from the dataset vectors. Environment-specific tumor, dose, termination, and
episode metrics are retained in the metrics fields.

## What Is Not a Public Variant

The catalog deliberately has no `mixed` datasets and no size-specific IDs such
as `expert-5k`, `expert-50k`, or `expert-100k`. A behavior-policy checkpoint
can still be used through the lower-level collector for custom experiments,
but it is not one of the curated public dataset variants.

To inspect or build a curated dataset:

```bash
python scripts/bench.py dataset list
python scripts/bench.py dataset show epicare/smart/final
python scripts/bench.py dataset build epicare/smart/dev
python scripts/bench.py dataset build dtr-ahn-chemo/setting1/random/dev
python scripts/bench.py train dtr-ghaffari-cancer/setting1/random/dev bc
```

The array-level contract, propensity fields, and metadata requirements are
defined in [Data schema](data-schema.md). Environment semantics and
observation/action spaces are defined in [Benchmarks](benchmarks.md).
